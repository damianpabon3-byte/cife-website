# CIFE v3.1 — Scroll-Reveal Animations (mini-spec)

**Date:** 2026-07-10 · **Approved by Damian in-session** (follow-up to v3).

One motion, everywhere: content **fades in and rises 12px over 0.45s** as it enters
the viewport, with a ≤280ms sibling stagger inside grids. Nothing else animates.

- **CSS** (`css/style.css`): `.reveal` (hidden state) / `.reveal.revealed` (shown);
  explicit `prefers-reduced-motion` override keeps everything visible and static.
- **JS** (`js/reveal.js`, new, ~30 lines, no dependencies): `IntersectionObserver`
  (threshold 0.1, bottom rootMargin −40px) adds `.revealed` once per element, then
  unobserves. Targets are auto-selected — `.hero-text`, `.hero-photo`, `.page-head`,
  `.card`, `.feature`, `.service-text`, `.service-media`, `.gallery-item`,
  `.testimonial-card`, `.cta-coupon`, `.stat`, `.section-heading` — so page HTML
  needs no per-element edits.
- **Progressive enhancement:** elements are visible by default in HTML; JS applies
  `.reveal` only when it runs AND motion is allowed AND `IntersectionObserver`
  exists. JS failure = static v3, never hidden content.
- **Script order matters:** `reveal.js` loads LAST (after `render.js`/`i18n.js`) so
  data-driven gallery/testimonial nodes exist when the observer attaches. Nodes
  re-rendered on language switch appear statically (no re-animation) — intended.
- **Cache rule applied:** all asset references bump `?v=3` → `?v=4`.

Files touched: `css/style.css`, `js/reveal.js` (new), all 7 `*.html` (script tag +
version bump).
